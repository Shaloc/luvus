## Notification popup and chrome refinements

- Render remote chrome with each display's terminal palette, preserving owner and passive-client isolation. Without a terminal color probe, None keeps default backgrounds instead of dark ANSI fills or fabricated child RGB replies; allow bounded SSH latency during startup probing.
- Use the canvas background for context menus, continuous corner backgrounds, and full-width selection fill. Collapse ordinary notification previews after five seconds while keeping history accessible from a compact count.
- Let host context-menu selection follow mouse hover, including after keyboard navigation, without sending input to remote panes.
- Move the optional notification inbox to a bottom-bar preview and a bordered floating history panel; preserve remote aggregation without covering sidebar controls or resizing panes.
- Simplify status details, remove the bottom version label, and show shortcut guidance only while the prefix is active.
- Complete rounded Menu and prefix controls, choose readable text on filled accents, and keep stable per-host badge colors with readable text. Round both ends of pane control strips and context-menu highlights; pane-title hover preserves its fill and underlines the title.
- Keep None's terminal canvas unchanged while giving its status bar a subtle, terminal-derived background.
- Keep focused pane IDs and agent status visible by default, include pane IDs in hover details, and show owner-aware prefix hints in remote workspaces.
- Show selection-copy request feedback even when SSH/OSC 52 cannot return a native clipboard success receipt.
- Synchronize rounded-corner changes from local Settings to running sessions on connected selected hosts, using the existing preference fanout without restarting owners.
- Stage installer downloads, extraction and executable validation inside the installation directory, so installation does not require running programs under `/tmp`.

## Remote event stream backpressure

- Keep the event subscription's receive-side disconnect probe from shortening the bounded send timeout on Unix sockets, allowing brief slow-reader pauses without truncating events.
- Drain managed SSH session events while snapshots load, and coalesce changes already covered by a snapshot instead of opening one SSH request per queued event.
- Resubscribe with a fresh sequence after event-history overflow or owner replacement; retain existing generation checks and cancellation ownership.
- Preserve underlying event-read errors and distinguish subscription write timeouts, write failures and queue overflow in server logs.
