## Kitty graphics

- Display inline virtual images that scroll with text, including tele-style photo and mosaic placeholders, with pane-scoped image IDs and named cleanup.

- Display direct-transfer Kitty images in local and managed remote panes, with pane clipping and menu overlays.
- Update images without resending unchanged text or replacing their client-side IDs, and preserve image metadata when `NO_COLOR` is set.
- Use transport 11 builds on the display machine and remote owners for graphics; older managed owners retain text support.

This stable release includes the fork's Qoder CLI support, One themes, managed remote
sessions, reconnect fixes and confirmed remote installation. It does not promise
full Kitty protocol support or 60 FPS browser rendering. See the fork release
page for macOS ARM64 and Linux x86_64 artifacts and verification details.

## Upstream fixes and remote compatibility

- Require an observed agent transition before a prompt wait completes, and reject prompts while Codex is displaying startup or interaction screens.
- Add optional terminal identity and content revision checks to `agent.keys`, and return the matching coordinates with `agent.read`.
- Permit `pane.rename` through scoped UHP Control Access.
- Run native clipboard copy outside the UI loop, bound helper waits, and wake idle clients on failure. Retire clipboard notifications when switching local or remote owners.
- Wait for theme configuration persistence before removing a custom theme, preserving remote preference refresh.
